01 / THE IDEA

Capability belongs to the agent.
Not the platform.

UCU is designed for AI systems that can understand screenshots but lack built-in desktop control. Rather than modifying or retraining the model, it provides an external execution bridge.

01 — ACCESS

Universal by design

Designed around screenshots and standard input events, not a single vendor's proprietary computer-use interface.

02 — CONTROL

Runs where you work

A local runtime executes actions on the user's machine. The website itself does not request desktop access.

03 — FEEDBACK

Verify every step

The proposed loop re-observes the screen after actions, so an agent can detect changes and correct its next move.

02 / EXECUTION LOOP

See. Reason. Act. Verify.

A simple interaction contract keeps the model and operating system separate. UCU handles the bridge; the connected agent supplies visual interpretation and decisions.

03 / ENGINEERING PRINCIPLES

Power needs boundaries.

Computer control is a high-trust capability. The runtime architecture is being developed with explicit permissions and observable actions as priorities.

Local-first control

Keep desktop execution in a local process and make trust boundaries explicit. Avoid silently turning a website into a remote-control console.

Traceable operations

Prioritize action logs, verification and recovery pathways, so users can inspect what the runtime attempted and what actually happened.

No model retraining

UCU is not a foundation model. The design integrates external capable models without requiring changes to their weights.

Open engineering

Apache License 2.0, public repository, and documentation as the runtime matures. No unverified installer is published here.
