01 / THE IDEA

Capability belongs to the agent.
Not the platform.

UCU is designed for AI systems that can understand screenshots but lack built-in desktop control. Rather than modifying or retraining the model, it provides an external execution bridge.

01 — ACCESS

Universal by design

Designed around screenshots and standard input events, not a single vendor's proprietary computer-use interface.

02 — CONTROL

Runs where you work

A local runtime executes actions on the user's machine. The website itself does not request desktop access.

03 — FEEDBACK

Verify every step

UCU re-observes the screen after actions, helping the agent detect changes and correct its next move.

02 / EXECUTION LOOP

See. Reason. Act. Verify.

A simple interaction contract keeps the model and operating system separate. UCU handles the bridge; the connected agent supplies visual interpretation and decisions.

04 / INTEGRATION APPROACH

Connect the reasoning.
Keep control local.

UCU is intended for agents with visual reasoning and permitted local tooling. Integration requires an explicit local runtime and an observe–act–verify loop, not a website permission prompt.

01 / HOST

Prepare your agent

Use a host that can inspect screenshot images and run approved local commands. Tooling permissions still apply.

02 / LOCAL

Connect a local runtime

UCU can be used now. Connect it through a compatible AI agent host and follow the project's setup instructions; verify local permissions before enabling desktop control.

03 / VERIFY

Observe every outcome

Capture the actual desktop, act only with appropriate authorization, then check the resulting pixels before continuing.

UCU and U2C are the same project. View the public source repository. The Python package and CLI retain the u2c namespace.
05 / ENGINEERING PRINCIPLES

Power needs boundaries.

Computer control is a high-trust capability. UCU prioritizes explicit permissions, observable actions and safe recovery.

Local-first control

Keep desktop execution in a local process and make trust boundaries explicit. Avoid silently turning a website into a remote-control console.

Traceable operations

Prioritize action logs, verification and recovery pathways, so users can inspect what the runtime attempted and what actually happened.

No model retraining

UCU is not a foundation model. The design integrates external capable models without requiring changes to their weights.

Open engineering

UCU is available for use now, with open development under Apache License 2.0 and project documentation on GitHub.

06 / OPEN SOURCE

Open source.
Ready to use.

UCU is available now and open source under Apache-2.0. The public repository includes the installer, setup guide, offline dependency bundle, and a release wheel containing the readable Python runtime source. UCU and U2C are the same project; the Python package and CLI retain the u2c namespace.
